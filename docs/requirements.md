# Requisitos editoriales y funcionales

## Ruta guía para la OVA

- Mostrar el recorrido completo antes de iniciar.
- Indicar ubicación, avance y siguiente módulo.
- Mantener navegación por teclado y móvil.
- Ruta: bienvenida, ecosistema móvil, Kotlin, Android Studio, diagnóstico, aplicación, evaluación y cierre.

## Audios y Adobe Podcast

- Conservar el audio original.
- Procesar voz y ruido mediante Adobe Podcast.
- Guardar la versión optimizada con nombre y fecha.
- Incorporar transcripción y control de velocidad.
- No bloquear el avance si el audio falla.

## Imágenes interactivas

- Usarlas para estructuras extensas como Android Studio y arquitectura de una app.
- Permitir activación por clic y teclado.
- Proporcionar alternativa textual completa.
- Evitar texto importante incrustado únicamente en la imagen.
- Mantener legibilidad sin desplazamiento horizontal en móvil.

## Correcciones anteriores

- Interfaz completamente en español.
- Corregir tildes, palabras pegadas y restos editoriales.
- Presentar el diagnóstico después de Android Studio y antes de las prácticas.
- Integrar las actividades originales dentro del recorrido React.
- Verificar el guardado real del progreso.
- Reparar recursos que no cargan.
- Añadir fuentes y fechas a afirmaciones cambiantes.
