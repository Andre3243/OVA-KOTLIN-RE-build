# OVA Kotlin · React

Nueva versión de la OVA “Primeros pasos en la programación móvil con Kotlin”.

## Estado inicial

- React + TypeScript + Vite.
- Ruta guía de seis módulos.
- Navegación adaptable y accesible.
- Requisitos editoriales documentados.
- Preparado para migrar las actividades originales a componentes React.

## Ejecutar

```bash
npm ci
npm run dev
```

## Verificar

```bash
npm run build
```

La introducción incluye el pódcast de bienvenida y un resumen para lectura.
