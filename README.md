# OVA Kotlin · React

Nueva versión de la OVA “Primeros pasos en la programación móvil con Kotlin”.

## Estado inicial

- React + TypeScript + Vite.
- Ruta guía de seis módulos.
- Navegación adaptable y accesible.
- Requisitos editoriales documentados.
- Preparado para migrar las actividades originales a componentes React.

## Ejecutar

```bash
npm ci
npm run dev
```

## Verificar

```bash
npm run build
```

La introducción incluye una versión de lectura. Si tienes autorización para usar el pódcast, puedes colocar una copia local en `public/media/conversacion.mp3`. El audio local está excluido de Git.
